# Aetheria v0.0.1

首个正式 Release，提供 Windows、Linux 和 Android 的完整构建产物。

## 音乐库与播放

- 基于 Flutter + Rust 的本地音乐播放器，支持音乐导入、元数据与封面提取、文件去重、标签和歌单管理。
- 同一首歌可管理多个音源版本，支持默认版本切换、播放、导出和删除。
- 支持音量均衡、峰值保护、音高调整、Rubber Band / resample 算法，以及局域网音乐库镜像同步。
- Android 提供播放通知、MediaSession、系统悬浮歌词与可选 SuperLyric 集成。

## 双语歌词修复

- 修复音频内嵌歌词、本地 LRC 等来源把原文和翻译按独立条目显示的问题。
- 当原文与翻译分为两整段、但拥有相同时间戳时，按时间点合并为一组，原文和翻译一起显示。
- 滚动歌词、候选预览、桌面与 Android 悬浮歌词、SuperLyric 统一使用同一套时间轴解析。
- 保留已有网易云翻译歌词的正确显示，并增加相同时间戳、重复行、逐字与偏移等解析回归覆盖。

## Linux 桌面支持

- 提供 Linux runner 与 Rust 原生音频构建支持。
- 新增 GTK 透明悬浮歌词窗口、样式设置、锁定穿透、拖动与位置回传。
- 补齐应用图标和桌面入口；发布压缩包包含可移植安装脚本。
- 优化歌曲详情抽屉和列表定位动画，减少 Linux 大面积模糊滤镜造成的界面停顿。

## 自动发布

- 发布工作流只需填写版本号，即可锁定最新 main 提交、执行分析与测试，并构建各平台产物。
- Android APK / AAB 使用正式签名；Windows 打包完整运行库；Linux 安装时生成实际路径的桌面入口。
- 所有平台构建成功后统一上传，校验文件大小与 SHA-256，再发布为正式 Latest Release。
- 附带校验文件和构建来源信息，已发布版本受到覆盖保护。
